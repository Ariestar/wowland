# 生产简报：六角宫灯 · SM_PalaceLantern_6S

**项目：** 桃源·上元灯会（元宵节主题 3D 互动场景）
**日期：** 2026-11-14
**资产类型：** 场景道具 / Hero Prop（主街悬挂灯）
**目标平台：** Unity URP（团结引擎 1.5+）/ 抖音小游戏，移动端优先
**美术风格：** 上元灯会 · 暖色发光 · 风格化写实（Stylized Realistic）

## 规格

| 项 | 取值 | 依据 |
|---|---|---|
| 灯笼类型 | 六角宫灯（Hexagonal Palace Lantern） | 宫灯是上元灯会主街最有辨识度的灯型；六角比八角更省面数，比四角更华丽 |
| 外形尺寸 | 灯体宽 0.60 m（对角），灯体高 0.66 m，含灯顶/灯底/流苏总高 1.93 m | 真实宫灯尺度，适合 3 m 左右檐下悬挂 |
| 三角面预算 | LOD0 ≤ 10,000 tris | 项目移动端；道具标准档 5,000–15,000 tris |
| 材质数量 | 4 个：纸罩、木框、鎏金、流苏 | Hero Prop 3–5 个材质 |
| 贴图预算 | 本版为纯材质色，不依赖贴图；后续烘焙按 1024–2048 准备 | 移动端 ASTC |
| UV | 1 套 UV，箱式/智能展开，0–1 范围 | 后续可加 Lightmap UV |
| 枢轴（Pivot） | 顶部吊环中心；灯笼整体向 −Z 悬挂 | 悬挂类道具的旋转/摆动枢轴 |
| 朝向 | 正面面板朝 −Y（Blender 标准前向） | 便于 Unity 中旋转摆放 |
| 导出 | `.blend` + `.glb` + `.fbx`，1 Blender 单位 = 1 米 | Unity 与通用管线 |

## 结构拆分

1. **骨架（Frame）**：6 根立柱、上下各 6 根横梁、6 根圈梁；对应传统宫灯“六柱、 curved beams、斜撑”的结构逻辑。
2. **灯罩（Lampshade）**：6 片微弧绢面，薄实体；纸面自发光，供引擎 Bloom 提亮。
3. **装饰（Decoration）**：六角攒尖顶、翘角、宝顶、吊环、上下鎏金压边、正面/背面“福”字金牌、底部结珠与 20 股流苏。

## 技能与工具

- `blender-director`：生产流程、阶段门禁、资产标准
- `blender-mcp-workflow`：Blender 5.x API 规范、命名、验证脚本
- `blender-modeler`：网格、修改器、拓扑清理
- `prop-artist`：道具尺度、轮廓、材质/枢轴规则
- `materials`：Principled BSDF 参数
- `export-pipeline`：GLB / FBX 导出

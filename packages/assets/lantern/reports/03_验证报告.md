### 3.5 已修正的导出问题

初次导出的 GLB/FBX 节点带有 `2.95 m` 的场景悬挂高度偏移（灯笼在预览场景中的位置被烘进节点），在 Unity 中实例化会悬空。已改为：

- **干净资产**（`SM_PalaceLantern_6S.blend`）：对象在原点，网格从吊环顶部向下延伸，导出节点无偏移；
- **预览场景**（`SM_PalaceLantern_6S_lookdev.blend`）：使用共享网格的渲染副本挂在 2.95 m，灯光/相机/背景只存在于该文件。

复检结果：GLB 节点无 translation，FBX 导入位置 (0,0,0)。

## 5. 复现方式

```powershell
# 建模、材质、灯光、六视角渲染、GLB/FBX 导出
blender -b --python assets/lantern/scripts/build_palace_lantern.py

# 资产规范门禁
blender -b assets/lantern/exports/SM_PalaceLantern_6S.blend `
  --python <blender-mcp-workflow>/scripts/validate_asset.py `
  -- --args-file <validate_args.json>

# 导出（Unity 预设 FBX / 通用 GLB）
blender -b assets/lantern/exports/SM_PalaceLantern_6S.blend `
  --python <export-pipeline>/scripts/export_asset.py `
  -- --args-file <export_args.json>

# 渲染后处理
python assets/lantern/scripts/postprocess_renders.py
```

## 6. 限制与后续工作

- 未在团结引擎 / Unity URP 中实际导入验证；GLB/FBX 仅做文件级与 Blender 回读级验证。
- 未制作 LOD、碰撞代理、Lightmap UV；当前为单一 LOD0。
- 材质为纯色 Principled BSDF，无贴图；后续若需要木纹、绢面纹理或做旧污渍，需补 UV 与烘焙流程。
- 自发光强度（Paper Emission Strength 1.4）为预览值，需按 URP Bloom 阈值在引擎内微调。
- 未包含动画、悬挂摆动脚本或点光组件；场景中建议由引擎侧添加点光/体积光。
- 渲染图为美术预览，不是最终游戏内截图。

# 灯笼 3D 建模最佳实践调研

**项目：** 桃源·上元灯会
**调研日期：** 2026-11-14
**目标资产：** 可复用的上元灯会悬挂灯笼（六角宫灯）
**目标管线：** Blender 5.3 → Unity URP / 抖音小游戏（移动端）

---

## 0. 调研结论

1. **先选灯型，再谈建模。** 上元灯会场景常用四类灯：圆形纸灯笼、六角/八角宫灯、走马灯、河灯。主街悬挂灯选六角宫灯：轮廓最像“灯会”，六向对称便于参数化复制，面数比八角低，适合移动端。
2. **结构优先于细节。** 学术论文把传统宫灯拆成 **骨架（frame）、灯罩（lampshade）、装饰（decoration）** 三部分，分别建模再组合，是兼顾造型准确与可控面数的核心方法 [1]。传统宫灯的骨架由立柱、横梁、圈梁、斜撑组成，装饰集中于顶部、底部和四周 [1][3]。
3. **轮廓与比例优先。** 道具流程应先做参考与灰盒，用基础体块确认轮廓、比例、悬挂方式，再进入细节 [6]。宫灯的关键轮廓是：六角柱身、外挑的攒尖顶、底部收分、下方流苏形成的纵向节奏。
4. **纸罩用几何微弧 + 法线细节，不靠堆面。** 论文中的实测做法是 UV 展开后用 normal map 模拟纸张微皱与凹凸，可在不增加顶点的情况下显著提升真实感 [1][5]。本资产用 6 片低面数微弧面板 + Solidify 解决厚度，后续量产版可把纸纹烘到法线贴图。
5. **材质按“纸 / 木 / 金 / 布”分开，控制在 4 个。** Hero Prop 建议 3–5 个材质 [7][8]。纸罩单独自发光材质，木框和鎏金分开以保留金属反射，流苏用高粗糙度布料。
6. **移动端发光靠 Emissive + Bloom，实时点光要限量。** 场景内几十上百盏灯若每盏都带实时点光会拖垮手机；正确做法是纸罩自发光 + 屏幕后处理 Bloom，只对关键位置的 8–16 盏保留真实点光 [9][10]。
7. **命名、枢轴、尺度、验证都要在交付前锁定。** 悬挂类道具的枢轴放在吊环中心，导出 1 单位 = 1 米；导出前用 `validate_asset.py` 检查变换、三角面、非流形、UV、材质槽和命名 [11]。

## 1. 灯笼类型对比与选型

| 类型 | 典型造型 | 建模难度 | 面数潜力 | 适用位置 | 本项目取舍 |
|---|---|---|---|---|---|
| 圆形纸灯笼 | 球状/扁球，竖向褶皱，上下收口 | 低 | 低（300–1,500） | 街道两侧成排、远景 | 作为后续量产填充灯 |
| 六角宫灯 | 六棱柱灯身 + 攒尖顶 + 流苏 | 中 | 中（4,000–10,000） | 主街、檐下、入口 | **本资产采用** |
| 八角宫灯 | 八棱柱，层次更多，装饰面更大 | 中高 | 中高（6,000–14,000） | 广场、主灯楼 | 暂不做，主灯楼另案 |
| 走马灯 | 旋转内胆 + 外框，需动画 | 高 | 中 | 灯谜摊、视觉焦点 | 首版不做 |
| 河灯 | 莲花/船形底座 + 小灯 | 中 | 低（500–2,000） | 河岸放灯玩法 | 后续单独建模 |

选型理由：

- 上元灯会的主街需要“抬头就能认出是灯会”的标志性轮廓，宫灯的六角攒尖顶比圆灯笼更有建筑感。
- 六角形可用 6 次旋转复制完成骨架，制作效率高，也便于做同系列变体（四角、八角）。
- 六角比八角少 2 个面，在移动端同屏几十盏时更友好。

## 2. 传统宫灯的结构与部件

### 2.1 三大部分

论文将传统灯笼明确拆为 **frame（骨架）、lampshade（灯罩）、decoration（装饰）**，并建议通过基础几何体 + 布尔运算（union / difference / intersection）逐层搭建，而不是从一个球体直接雕刻 [1]。

### 2.2 骨架

- 传统宫灯以 **细木为骨架**，灯罩用绢纱或玻璃，表面可绘制花鸟、山水、吉祥纹样 [2]。
- 六角宫灯的框架借鉴建筑梁柱体系，常见 **六根大柱、六根小柱、弧形梁、斜撑** 等构件 [3]。
- 对 game-ready 模型，骨架用方形截面梁 + 小倒角即可；真实榫卯、雕花不进入低模，靠贴图/法线表达。

### 2.3 灯罩

- 宫灯灯罩是透光绢纱/玻璃，纸面或绢面应有轻微张力弧度，不应是完全平面。
- 圆形纸灯笼的竖向褶皱是纸材自然的折痕；宫灯则更多是平面绢面 + 木格栅。两者不要混用褶皱语言。
- 纸面微皱、纤维纹理用 normal map / bump 表达 [1][5]。

### 2.4 装饰

- 顶部：攒尖顶（六角/八角坡屋顶）、翘角、宝顶、吊环。
- 底部：收分底座、垂珠、流苏。
- 四周：鎏金压边、角花、吉祥字（福、寿、喜）、宫灯画片。
- 论文中的装饰通过差集、镜像和循环阵列生成，特别是流苏用圆柱按固定角度间隔环绕排列 [1]。

## 3. 推荐建模流程

```
1. 参考收集（多角度、材质、尺寸、结构）
2. 灰盒 / 比例确认（只做剪影，不做细节）
3. 中模（骨架、灯罩、主要装饰）
4. 高模细节（翘角、宝顶、雕花、流苏）
5. 低模整理（去内面、合并、倒角、命名）
6. UV 展开（0–1，预留 Lightmap）
7. 材质与灯光（Principled BSDF + 自发光）
8. 多角度渲染检查（前/侧/后/顶/3-4）
9. 验证 + 导出（GLB / FBX）
```

这套顺序来自 Poly Haven 的 Simple Prop Workflow：Planning → Blocking → Modeling (High + Low) → UV → Baking → Texturing → Final Delivery [6]。其中“Blocking 先锁定剪影与比例”是避免后期返工的关键。

### 3.1 参考与尺寸

- 收集同类型宫灯的正视、侧视、仰视、细节图；同时收集真实木纹、鎏金、绢布、流苏的材质参考。
- 先确定悬挂高度与灯体尺寸。普通建筑檐口约 2.8–3.2 m，宫灯总高（含流苏）1.2–1.8 m 较合适；灯体宽 0.4–0.8 m。
- 本项目取灯体宽 0.60 m、灯体高 0.66 m、总高约 1.93 m（含较长流苏，适合主街悬挂的视觉分量）。

### 3.2 灰盒与轮廓

- 用六棱柱、圆锥、圆柱做 5 分钟灰盒，先看剪影：灯身是否够“鼓”、屋顶是否外挑、流苏是否形成纵向收尾。
- 灰盒阶段只保留 6–8 个基础体，不碰细节。
- 将灰盒单独放到 `COL_Blockout`，确认后再做正式模型。

### 3.3 参数化与对称

- 六角宫灯 6 次旋转对称：建 1 根立柱 + 1 根横梁 + 1 片灯罩，然后用 60° 旋转复制。
- Blender 中可用 Array（Circular）或直接 Python 循环生成；本资产采用参数化脚本，保证每个构件都精确落在六边形顶点上。
- 参数化便于后续生成四角/八角变体，也便于改尺寸。

### 3.4 硬表面与软性部分分开

- 骨架、鎏金件：硬表面，使用倒角（Bevel）2–3 段，保持边缘高光。
- 灯罩：软性薄面，使用网格 + Solidify（0.002–0.004 m），不要用厚立方体。
- 流苏：低面数圆柱/锥体束，或用带 alpha 的卡片；不要真做几百根曲线。

### 3.5 拓扑规则

- 以四边形为主；灯罩网格用规则栅格；骨架梁用长方体 + 倒角。
- 避免 n-gon（>4 边面），导出前三角化；`validate_asset.py` 会将 n-gon 标为 WARN。
- 所有闭合件保持流形（manifold），不允许游离点/线。
- 对称件保持完全对称，避免视觉上的“歪”。

## 4. 细节与材质最佳实践

### 4.1 纸罩

- 基础色用深朱红，不要用纯红 `(1,0,0)`；真实绢纱在暖光下偏橙红。
- 纸罩厚度很薄，几何上用 Solidify；渲染时纸面自发光，内部可放 1–2 盏点光做透光。
- 纸纹、纤维、折痕用 normal map，不要用 displacement 堆几何 [1][5]。
- 若要表现“灯笼从里面亮起来”，纸面 Emission 颜色应偏暖橙（#FF6A2A），强度 2–3；不要整面纯白过曝。

### 4.2 木框

- 深红木/紫檀色，Roughness 0.4–0.6，Metallic 0；可加少量 Coat 提漆面反光。
- 倒角宽度 2–4 mm，2 段；梁与柱交接处允许轻微穿插，但外露部分要干净。
- 木纹用程序纹理或贴图；game-ready 版可用纯色 + AO/曲率贴图。

### 4.3 鎏金

- Metallic 1.0，Roughness 0.25–0.35，基础色偏旧金 `#D9A441`，不要纯黄 `(1,0.84,0)`。
- 翘角、压边、宝顶、吊环用同一材质，减少材质数量。
- 金属高光在 EEVEE/URP 中依赖环境反射；场景里需有环境探针或反射球，否则会发黑。

### 4.4 流苏

- 布料：Metallic 0，Roughness 0.8–0.9，可加 Sheen 0.2–0.4。
- 流苏不要用物理模拟；用 16–24 根锥形圆柱围绕圆心排列，长度做 5%–10% 随机差异即可。
- 若同屏数量多，可把流苏做成一张 alpha 卡片（2 个三角形），远景切换。

### 4.5 发光策略（移动端）

| 方案 | 开销 | 适用 |
|---|---|---|
| 纸面 Emissive + Bloom | 低 | 所有灯笼默认 |
| 灯笼内部 1 盏点光 | 中 | 主角灯、近景 8–16 盏 |
| 每盏灯实时点光 + 阴影 | 高 | 不推荐 |
| Lightmap + Emissive 假光晕 | 最低 | 静态街景、远景 |

Unity URP 的性能文档建议：减少实时灯光数量、使用烘焙光照、控制阴影距离与分辨率、合并材质与网格以减少 SetPass/Draw Call [9][10]。移动端同屏真实点光控制在 8–16 盏，其余用自发光和烘焙。

## 5. 游戏就绪与导出

### 5.1 面数预算

| 档位 | 三角面 | 用途 |
|---|---|---|
| Hero Prop | 2,000–8,000 | 玩家近看、交互物 |
| Standard | 500–2,000 | 中景道具 |
| Background | 100–500 | 远景填充 |

本资产按 Hero 档制作，控制在 10,000 tris 以内（含装饰与流苏），并预留 LOD1（约 40% 面数）用于中远景。

### 5.2 材质与 Draw Call

- 4 个材质：纸、木、金、布。
- 同材质灯笼尽量共用材质实例；URP 中开启 SRP Batcher，可显著减少重复材质的开销。
- 若同屏数量极大，可将 4 个材质合并为 1 张 atlas（纸/木/金/布各占一块），代价是贴图精度下降。

### 5.3 UV

- 至少 1 套 UV，0–1 范围；需要烘焙光照时再加 Lightmap UV。
- 纸罩用规则栅格 UV；木框/金属件可用 Smart UV 或箱式投影。
- 贴图之间留 2–4 px padding，避免采样漏色 [5]。

### 5.4 命名与层级

```
COL_Lantern
├── COL_Export
│   └── SM_PalaceLantern_6S        # 最终合并网格
├── COL_Geo                         # 制作中的零件（合并前）
├── COL_Lights                      # LGT_
├── COL_Cameras                     # CAM_
└── COL_Render                      # 渲染辅助（横梁、背景灯）
```

- 网格：`SM_PalaceLantern_6S`
- 材质：`MAT_Lantern_Paper` / `_Wood` / `_Gold` / `_Tassel`
- 灯光：`LGT_`
- 相机：`CAM_`

### 5.5 枢轴与导出

- 枢轴：顶部吊环中心（悬挂点），灯笼向下延伸；这样在 Unity 中做风吹摆动时绕吊环旋转，符合物理直觉。
- 导出：GLB（+Y Up，选中对象，应用修改器）+ FBX（-Z Forward / Y Up，Apply Unit，Scale 1.0）。
- 1 Blender 单位 = 1 米；Unity 导入后不需要额外缩放。

## 6. 常见错误清单

| 错误 | 后果 | 修复 |
|---|---|---|
| 用立方体直接做灯罩 | 灯罩像盒子，没有绢面张力 | 用微弧栅格 + Solidify |
| 每片纸罩单独材质 | Draw Call 翻倍 | 合并为 1 个纸材质 |
| 纸面纯红、无自发光 | 夜景里灯不亮，像红盒子 | Emission + Bloom |
| 每盏灯都带点光 | 手机掉帧、发热 | 只给近景 8–16 盏，其余烘焙 |
| 流苏用曲线/毛发 | 面数爆炸、导出慢 | 锥形圆柱束或 alpha 卡片 |
| 未应用缩放/旋转 | 导出后比例错误、法线异常 | 导出前 Apply Transform |
| n-gon 未三角化 | 引擎里三角化不可控、阴影错误 | 导出前三角化 |
| 枢轴在灯体中心 | 摆动像绕自身转，不像悬挂 | 枢轴放吊环中心 |
| 不做 UV | 无法贴图/烘焙 | 至少 1 套 UV |
| 多材质槽空槽 | 引擎导入报错/浪费 | 清理空槽 |

## 7. 本资产的落地决策

| 决策 | 取值 | 理由 |
|---|---|---|
| 灯型 | 六角宫灯 | 上元灯会主街识别度最高，六向对称易参数化 |
| 尺寸 | 灯体 0.60 × 0.66 m，总高 1.93 m | 适配 3 m 檐口，视觉分量足 |
| 三角面 | 约 6,000–9,000 tris | 落在 Hero Prop 预算内 |
| 材质 | 4 个 | 纸/木/金/布，满足 PBR 与移动端 |
| 纸罩 | 微弧栅格 + Solidify + Emission | 几何省面，发光效果靠材质 |
| 装饰 | 六角攒尖顶、6 翘角、宝顶、吊环、福字、流苏 | 覆盖论文中的 frame / lampshade / decoration 三部分 |
| 枢轴 | 吊环中心 | 悬挂摆动正确 |
| 导出 | GLB + FBX | Unity 与通用管线 |

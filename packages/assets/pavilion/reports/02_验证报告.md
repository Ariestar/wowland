## 4. 建模要点（本版精细化）

- **台基**：须弥座三层轮廓（下枋 / 束腰 / 上枋），6 面束腰浮雕板，四级踏步 + 两侧垂带石，木地板与鎏金压边。
- **柱网**：6 根带收分与侧脚的朱红檐柱，方形柱顶石、鼓镜柱础、上下鎏金柱箍与柱头科。
- **梁架**：额枋、平板枋、小额枋三层；6 面青绿彩绘板 + 鎏金边框；12 个雀替。
- **斗拱**：12 组（6 柱头 + 6 补间），每组坐斗、两跳翘、令拱、2 个散斗、昂。
- **挂落**：5 面步步锦式檐下挂落，上下枋 + 竖棂 + 菱形斜棂。
- **屋顶**：连续六角曲面（10 × 12 段）按 `v^1.55` 抬升，檐角起翘 0.26 m，Solidify 0.07 m；42 条瓦垄、42 个瓦当、6 条垂脊、18 只脊兽、42 根檐椽；宝顶含须弥座、双层莲座、宝珠、刹杆与尖顶。
- **围栏**：五面美人靠，坐面高 0.42 m，靠背高 0.86 m，含望柱与鎏金柱头；正面留 1.85 m 入口。
- **装饰**：正面「上元亭」匾额（彩绘底、鎏金边框与四角花饰）；檐角 6 盏小红灯笼 + 亭内 1 盏大灯笼，灯笼带金色经线与流苏。

## 6. 复现方式

```powershell
# 建模、材质、灯光、九视角渲染、GLB/FBX 导出
blender -b --python assets/pavilion/scripts/build_pavilion.py

# LOD1 / LOD2 生成与导出
blender -b assets/pavilion/exports/SM_Env_Pavilion_Hex_01.blend `
  --python assets/pavilion/scripts/build_lods.py

# 资产规范门禁
blender -b assets/pavilion/exports/SM_Env_Pavilion_Hex_01.blend `
  --python <blender-mcp-workflow>/scripts/validate_asset.py `
  -- --args-file <pavilion_validate_args.json>

# 导出（Unity 预设 FBX / 通用 GLB）
blender -b assets/pavilion/exports/SM_Env_Pavilion_Hex_01.blend `
  --python <export-pipeline>/scripts/export_asset.py `
  -- --args-file <pavilion_export_args.json>

# 渲染后处理
python assets/pavilion/scripts/postprocess_pavilion_renders.py
```

## 7. 限制与后续工作

- 未在团结引擎 / Unity URP 中实际导入验证；GLB/FBX 仅做文件级与 Blender 回读级验证。
- LOD2 为极限减面版，5,704 tris、0 开放边界；25 m 内建议使用 LOD0/LOD1。
- 未制作碰撞代理与 Lightmap UV；当前为单一渲染网格。
- 材质为纯色 Principled BSDF，无贴图；瓦面纹理、木纹、石纹与做旧需在贴图阶段补齐。
- 屋顶瓦垄为几何线条，非逐片筒瓦/板瓦；近景如需真实瓦面，可叠加法线贴图或高模烘焙。
- 灯笼自发光强度为预览值，需按 URP Bloom 阈值在引擎内微调。
- 渲染图为美术预览，不是最终游戏内截图。

# 亭子设计最佳实践：从传统形制到游戏资产

**项目：** 桃源·上元灯会
**日期：** 2026-11-14
**对象：** `SM_Env_Pavilion_Hex_01`（六角亭）
**用途：** 说明本资产在形制、构图、拓扑、材质与 LOD 上的取舍，供后续亭、廊、戏台等同类建筑复用。

---

## 1. 先定形制，再做细节

传统六角亭可以拆成六个层级，建模顺序按“大形 → 中景构件 → 近景纹样”推进：

| 层级 | 构件 | 建模要点 |
|---|---|---|
| 台基 | 须弥座、踏步、垂带石 | 先定地面高差与踏步数，再给束腰和浮雕板；台基轮廓决定建筑落地感 |
| 柱网 | 檐柱、柱础、柱头 | 六柱六边，柱径与柱高比约 1:14；柱身做 3%–5% 收分与轻微侧脚 |
| 梁架 | 额枋、平板枋、小额枋、雀替 | 梁枋围合成六边形，雀替填柱梁夹角，是近景识别度最高的构件之一 |
| 斗拱 | 坐斗、翘、昂、令拱、散斗 | 柱头铺作 + 补间铺作成组出现；每层出挑 0.08–0.12 m，形成檐下阴影 |
| 屋顶 | 瓦垄、瓦当、垂脊、脊兽、翼角、宝顶 | 先做连续曲面，再叠瓦垄与垂脊；翼角起翘 0.2–0.3 m，宝顶用莲座 + 宝珠收束 |
| 围护/装饰 | 美人靠、挂落、匾额、灯笼 | 美人靠坐面约 0.42 m、靠背约 0.86 m；挂落与匾额提供“有人使用”的尺度参照 |

**比例经验：** 六角亭柱高约等于柱距的 1.3–1.4 倍；檐口挑出约 0.8–1.0 倍柱径的 4–6 倍；屋顶高度（檐口到宝顶）约占总高的 35%–40%。本资产柱高 2.55 m、柱距 1.85 m、总高 5.38 m，落在这一区间。

## 2. 游戏环境资产的设计原则

### 2.1 轮廓优先

移动端和小游戏画面里，建筑先以剪影被识别。优先级：

1. 屋顶曲线与檐角起翘（决定“中式亭”的第一印象）
2. 台基宽度与踏步（决定建筑落地与可进入性）
3. 柱列节奏（决定开间与通透感）
4. 斗拱、挂落、脊兽（近景才需要）

本资产把 6 条垂脊、6 个翘角、宝顶和 6 盏檐灯放在轮廓线上，保证 20–30 m 外仍有清晰剪影。

### 2.2 宏观 / 中观 / 微观三级细节

| 距离 | 可见内容 | 本资产做法 |
|---|---|---|
| 20–40 m | 屋顶、台基、柱网、灯笼 | 体块与发光点 |
| 8–20 m | 斗拱、挂落、美人靠、匾额 | 中等尺度几何，约 0.1–0.4 m |
| 0–8 m | 瓦垄、瓦当、脊兽、柱础、灯笼经线 | 毫米到厘米级几何；不依赖贴图也能读出层次 |

### 2.3 重复构件参数化

六角亭的优势是六向重复：柱、斗拱、雀替、挂落、瓦垄、脊兽都按 `for i in range(6)` 生成。修改一个参数即可整体调整，不用逐件手工摆。命名也按方位编号（`_01`…`_06`），便于后续替换或做变体。

### 2.4 材质与 Draw Call

移动端建议 4–7 个材质槽。本资产使用 6 个：石、木、金、瓦、彩绘、灯笼。彩绘单独成材质，是为了让梁枋在夜景中有青绿冷色对比，避免整亭只有红与黑。

### 2.5 LOD 与预算

| LOD | 面数 | 相对 LOD0 | 用途 |
|---|---|---|---|
| LOD0 | 30,818 | 100% | 0–10 m 近景、宣传图 |
| LOD1 | 13,868 | 45% | 10–25 m 中景 |
| LOD2 | 5,704 | 18.5% | 25 m+ 远景 |

LOD1 保持 0 非流形边、0 开放边界；LOD2 为极限减面版，同样保持 0 非流形、0 开放边界。减面产生的 229 个双面孤立三角片已在生成阶段自动清理，避免导出时被 `mesh.validate()` 剔除后留下破洞。

### 2.6 UV 与后续贴图

本版用 Smart UV Project 生成单套打包 UV，所有循环落在 0–1。后续进入贴图阶段时：

- 为瓦、木、石各做 1024–2048 的 tiling 材质
- 用 Trim Sheet 复用梁枋彩画与挂落纹样
- 需要光照贴图时，复制 UV 层并重新打包为 `UVMap_Lightmap`

## 3. 本资产的做法对照

| 最佳实践 | 本资产落实 |
|---|---|
| 先大形后细节 | 先建台基、六柱、曲面屋顶，再叠斗拱、挂落、瓦垄、脊兽 |
| 轮廓可读 | 翘角 + 垂脊 + 宝顶 + 檐灯形成 6 向剪影 |
| 结构可信 | 柱有收分与侧脚；斗拱分柱头/补间；梁枋有雀替与挂落 |
| 近景有内容 | 瓦垄 42 条、瓦当 42 个、脊兽 18 只、檐椽 42 根 |
| 尺度参照 | 柱高 2.55 m、坐面 0.42 m、台阶 0.115 m/级 |
| 材质克制 | 6 个材质，无贴图也能读出石 / 木 / 金 / 瓦 / 彩绘 / 纸 |
| 拓扑干净 | LOD0 0 n-gon、0 非流形、0 开放边界、0 松散几何 |
| 可进引擎 | 枢轴在台基中心地面，正面朝 −Y，GLB/FBX 原点导出 |
| 可扩展 | 参数化脚本 `build_pavilion.py`，改常量即可生成四角/八角变体 |

## 4. 参考

**传统建筑**

- 李诫，《营造法式》（1103）：台基、斗拱、瓦作与彩画制度的早期系统总结。
- 梁思成，《清式营造则例》（1934）：清式建筑比例、斗拱与屋顶做法的现代测绘与整理。
- 刘敦桢，《中国古代建筑史》（1980）：亭榭与园林建筑的类型与尺度参考。

**游戏资产与 Blender 流程**

- `blender-ai-plugin` / `environment-artist`：建筑尺度、模块化、轮廓与性能原则。
- `blender-ai-plugin` / `blender-modeler`：非破坏式建模、修改器顺序、拓扑清理。
- `blender-ai-plugin` / `asset-optimization`：三角面预算、材质数量、验证清单。
- `blender-ai-plugin` / `lod-pipeline`：LOD 命名、减面比例、屏幕尺寸切换。
- `blender-ai-plugin` / `blender-mcp-workflow`：`validate_asset.py`、`scene_audit.py` 与 Blender 5.x API。
